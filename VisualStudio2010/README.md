# NUVIO — projeto Xbox 360

Abra `NUVIO.sln` e compile **Release | Xbox 360** no Visual Studio 2010 com XDK instalado. O executável é `Release/NUVIO.xex`.

Consulte [README principal](../README.md) para operação, controles e limites, e [integração dos addons](../docs/CLOUD-ADDONS.md) para arquitetura e referências oficiais. Os testes são `run_core_tests.bat`, `run_auth_tests.bat` e `run_cloud_tests.bat`.

As dependências em ThirdParty são necessárias para HTTPS, TLS, JSON, imagens e QR. Preserve-as e suas licenças. O nome de distribuição do aplicativo é NUVIO.
